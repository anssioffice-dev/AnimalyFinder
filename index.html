trapcam.viewer
One-time setup — about 5 minutes
1 — Google Cloud project
Go to console.cloud.google.com and create a new project.
Go to APIs & Services → Library and enable Google Drive API.
2 — OAuth Client ID (Drive login)
Go to OAuth consent screen. Choose External. Fill in an app name and your email. Add all users under Test users.
Go to Credentials → Create Credentials → OAuth 2.0 Client ID. Type: Web application. Add your hosting URL under Authorised JavaScript origins. Copy the Client ID.
3 — Paste your keys
Your key is saved only in this browser. Photos go directly to Google — nothing passes through any third-party server.
