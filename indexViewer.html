trapcam.analyser
One-time setup — takes about 10 minutes
1 — Create a Google Cloud project
Go to console.cloud.google.com and create a new project (name it anything, e.g. Trapcam).
Go to APIs & Services → Library and enable both Google Drive API and Cloud Vision API.
2 — Create OAuth Client ID (for Drive login)
Go to APIs & Services → OAuth consent screen. Choose External. Fill in an app name and your email. Skip scopes for now.
On the Test users step, add the Google email of everyone who will use this app (including yourself and any friends).
Go to Credentials → Create Credentials → OAuth 2.0 Client ID. Type: Web application. Under Authorised JavaScript origins add http://localhost for local use, or your hosting URL. Copy the Client ID.
3 — Create Vision API key (free — 1,000 photos/month)
Go to Credentials → Create Credentials → API key. Copy the key. Optionally restrict it to Cloud Vision API only.
4 — Paste your keys below
From Credentials → OAuth 2.0 Client IDs
From Credentials → API Keys. Free up to 1,000 images/month.
Your keys are saved only in this browser (localStorage).
Photos go directly to Google Vision — nothing passes through any third-party server.
